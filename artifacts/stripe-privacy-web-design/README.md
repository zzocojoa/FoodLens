# Stripe-style legal page design previews

This folder contains non-canonical static design previews for the FoodLens legal page redesign.

- `index.html`: Korean Privacy Policy preview with language switcher
- `index.en.html`, `index.ja.html`, `index.zh-Hans.html`: localized Privacy Policy previews
- `terms-of-service.html`: Korean Terms of Service preview with language switcher
- `terms-of-service.en.html`, `terms-of-service.ja.html`, `terms-of-service.zh-Hans.html`: localized Terms of Service previews

The canonical published legal docs remain under `docs/privacy-policy/` and `docs/terms-of-service/`.

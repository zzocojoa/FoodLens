# FoodLens 사업 방향 메모

## 1. 포지셔닝

FoodLens는 "AI 음식 분석 앱"보다 **해외 여행자용 알레르기 안전 판단 도구**로 포지셔닝하는 것이 맞습니다.

- 사용자는 재미있는 인사이트보다 **실수 비용이 큰 순간의 안전 판단**을 원합니다.
- 경쟁 우위는 단순 사진 인식이 아니라 **개인화된 알레르기 경고와 현장 의사결정 UX**입니다.
- 특히 음식 사진 기반 판단은 사용자 진입점이 넓지만 불확실성이 높으므로, 결과는 항상 보수적 안전 신호 중심으로 표현해야 합니다.

## 2. 가장 좁은 진입점 (Wedge)

첫 번째로 가장 강한 제품 흐름은 다음입니다.

1. 실제 음식 또는 메뉴 사진 촬영
2. 어떤 음식인지 추정 + 사용자 알레르기 기준 위험 신호 표시
3. 필요 시 라벨 사진 또는 여행자 카드로 후속 확인 연결

포장식품 흐름은 다음 보조 경로로 설계합니다.

1. 바코드 조회가 되면 가장 빠른 확인 경로로 사용
2. 바코드가 지원되지 않으면 즉시 라벨 사진 분석으로 전환

즉 제품 중심축은 음식 사진 기반 안전 판단이고, 바코드는 빠른 성공 경로입니다.

## 3. 고객 문제

- 해외 식당이나 길거리 음식 앞에서 무엇인지, 먹어도 되는지 바로 판단하기 어렵다.
- 해외에서 낯선 식품을 봐도 성분을 빠르게 해석하기 어렵다.
- 언어 장벽 때문에 중요한 알레르기 경고를 놓친다.
- 기존 검색/번역은 느리고, 현장 의사결정에 최적화되지 않았다.

## 4. 타겟 고객

### 1차 고객

- 알레르기 또는 식이 제한이 있는 해외 여행자
- 가족 구성원의 알레르기 정보를 대신 관리하는 보호자

### 2차 고객

- 건강 관리 때문에 성분과 영양 정보를 확인하는 일반 여행자

## 5. 유통/성장 전략

- 초기 유입 채널은 여행 커뮤니티, 검색형 콘텐츠, 여행 크리에이터 협업이 적합합니다.
- "해외 음식 안전", "일본/동남아 편의점 라벨 읽기", "알레르기 여행 준비물" 같은 문제 중심 콘텐츠가 맞습니다.
- 유료 매체 집행보다 실사용 후기, 잘못 먹지 않도록 도운 사례, 여행자 카드 활용 사례가 신뢰를 만듭니다.

## 6. 수익화 방향

핵심 안전 순간의 신뢰를 해치지 않는 선에서 수익화해야 합니다.

- 기본 모델: 무료 진입 + 핵심 흐름 유지
- 후보:
  - 고급 분석/무제한 분석
  - 가족 프로필/다중 프로필
  - 여행자 카드 고급 옵션
  - 상세 리포트 내보내기

주의:

- 무료 사용량 제한이나 구독 안내는 안전 판단 직전 흐름을 방해하지 않아야 합니다.
- 수익화 메시지는 제품 신뢰를 대체하면 안 됩니다.
- 음식 사진 분석 결과를 과도하게 단정하는 유료화 메시지도 피해야 합니다.

## 7. 현재 리스크

- 공개 문서와 실제 구현이 한 목소리로 정렬되지 않으면 스토어 심사/사용자 신뢰에 문제가 생깁니다.
- 제품 정의가 넓어지면 "무엇을 위해 꼭 써야 하는 앱인지"가 약해집니다.
- 알레르기 제품은 과장 표현에 취약하므로, 항상 "의사결정을 돕는 보조 도구"로 표현해야 합니다.
- 바코드 커버리지가 낮은 상태에서 바코드를 메인 가치로 약속하면 실제 사용 순간과 제품 약속이 어긋납니다.

## 8. 다음 90일 우선순위

1. 포지셔닝 일원화
   - 앱 설명, README, 스토어 문구, 법률 문서를 모두 `음식 사진 중심 + 보수적 안전 판단` 정의로 통일
2. 음식 사진 wedge 지표 측정
   - 설치 -> 첫 음식 사진 분석 -> 결과 저장 -> 7일 재사용
3. 포장식품 fallback 강화
   - 바코드 실패 -> 라벨 사진 분석 전환 UX 고정
4. 신뢰 강화
   - 오분석 신고, support 흐름, privacy/terms, 결과 톤 명확화
5. 출시 운영 고정
   - Android 내부 테스트 -> staged rollout
   - iOS 배포 준비

## 9. 한 줄 요약

FoodLens의 사업성은 "AI 음식 분석" 일반론에 있지 않고, **해외 여행자 알레르기 안전 판단**이라는 좁고 강한 문제를 `음식 사진 메인 + 바코드/라벨 보조 경로`로 끝까지 푸는 데 있습니다.
